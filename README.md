# レンタルスペース 予約・売上ダッシュボード — 導入手順

Googleカレンダーの予約から、拠点別・月別の売上・手取り・利益のダッシュボードを作る Claude Code のスキルです。

## 事前に用意するもの

- Claude Code（claude.ai のアカウントでログイン）
- インスタベース・スペースマーケットなどの予約が、Googleカレンダーに自動で入る設定（各サイトのカレンダー連携）
- claude.ai の「設定 → コネクタ」で **Google Calendar** と **Gmail** を有効にしておく

## 入れ方

1. `rental-space-dashboard.zip` をダウンロードする（ダウンロードフォルダに入ればOK。解凍してもしなくても大丈夫です）
2. Claude Code を開いて、下の枠の文章をそのまま貼り付けて送る

```
レンタルスペースの売上ダッシュボードのスキルを入れたいです。次の順で進めて。

1. ダウンロードフォルダ（~/Downloads）から rental-space-dashboard.zip、または解凍済みの rental-space-dashboard フォルダを探す。見つからなければ、ほかの場所も探して、それでも無ければ私に聞く。
2. 中の rental-space-dashboard フォルダ（SKILL.md が入っているもの）を ~/.claude/skills/ の中に置く。~/.claude/skills が無ければ作る。同じ名前のフォルダが既にあれば新しいもので置き換える。
3. ~/.claude/skills/rental-space-dashboard/SKILL.md があること、python3 が使えることを確認する。python3 が無ければ入れ方を案内して止まる。
4. Google カレンダーと Gmail につながっているか、カレンダー一覧と Gmail の検索を1回ずつ試して確認する。つながっていなければ、claude.ai の「設定 → コネクタ」で有効にする手順を案内して止まる。
5. 全部そろったら、~/.claude/skills/rental-space-dashboard/SKILL.md を読んで「初回セットアップ」を始める。どのカレンダーがどの拠点（部屋）か、毎月の固定費はいくらかを私に聞いて、最初のダッシュボードまで作る。
6. 最後に、次回からは「ダッシュボード更新して」と言えば最新になること、そのために Claude Code を一度開き直す必要があることを教えて。
```

3. あとは聞かれたことに答えるだけです（どのカレンダーがどの拠点か、家賃・光熱費などの毎月の固定費）

## 使い方

- 「ダッシュボード更新して」「今月の売上どう？」でいつでも最新にできます
- 出来上がりは `~/rental-space-dashboard/dashboard.html`（ブラウザで開くだけ）

## 注意

- 金額は予約ベースの推定です。確定額は各サイトの月次明細で確認するのが確実です
- スペースマーケットの金額は予約通知メールから拾います。メールが見つからない予約は「金額不明」になります（1時間の料金を設定しておくと推定で埋まります）
- データは自分のパソコンの中だけに保存されます
